# История изменений

## 1.0.0 — 2026-08-13

- первый аппаратно-независимый release;
- транспорт через Ethernet WAN, Wi-Fi WAN или готовый LTE/5G-интерфейс;
- WireGuard/AmneziaWG, kill switch, ручное переключение и boot restore;
- optional remote SSH, downstream endpoint exceptions и modem clock hook;
- русская документация, примеры и CI-проверки без реальных секретов.
